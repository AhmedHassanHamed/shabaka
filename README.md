# شبكة | Shabaka

منصة تعريف بين أصحاب المشاريع والمستقلين العرب. يرشّح الموقع مستقلًا راجع فريقه أعماله، ويُنفَّذ المشروع بنظام دفع ثابت على مرحلتين. الموقع ثنائي اللغة (عربي / إنجليزي)، ويدعم الاتجاه من اليمين لليسار، والوضع الليلي.

## الفكرة

- **انتقاء قبل القبول:** يُقبل المستقلون بعد مراجعة أعمالهم السابقة.
- **دفع على مرحلتين:** 50% قبل البدء و50% عند الاستلام، مباشرة بين الطرفين.
- **عمولة واضحة:** لا رسوم على صاحب المشروع. عمولة المستقل 10% من قيمة المشروع بعد التسليم، بعرض إطلاق 5% خلال أول 3 شهور.
- **وسيط تعريف:** المنصة لا تحتفظ بأموال الطرفين.

## الخدمات

برمجة وتطوير، تصميم، تسويق رقمي، مونتاج وفيديو، كتابة محتوى وترجمة.

## الصفحات والمزايا

| الصفحة            | الوصف                                                                                                                                                                         |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `index.html`      | الصفحة الرئيسية: الخدمات، طريقة العمل، الدفع والعمولة، نموذج بدء مشروع خطوة بخطوة (لصاحب المشروع وللمستقل)، الأمان والثقة، الأسئلة الشائعة، من نحن، التواصل، الشروط والخصوصية |
| `community.html`  | مجتمع الطلبات: يكتب الأعضاء الخدمات التي يحتاجونها ولا يجدونها، ويصوّت الباقون لترتيب الأولويات. تُراجع المشاركات قبل النشر                                                   |
| `messages.html`   | رسائل خاصة بين صاحب المشروع والمستقل المرتبطين بمشروع واحد، لا يراها غيرهما                                                                                                   |
| `reviews.html`    | تقييمات المستقلين (من أصحاب مشاريع أتمّوا أعمالهم عبر المنصة) وتقييمات الموقع، مع متوسط التقييم لكل مستقل                                                                     |
| `profile.html`    | ملف العضو: اسمه ودوره (مستقل / صاحب مشروع) وتخصصه ونبذته ومعرض أعماله، ويُنشر بعد المراجعة                                                                                    |
| `freelancer.html` | الصفحة العامة للعضو: عضو منذ، مشاريع مكتملة، متوسط التقييم، النبذة، التقييمات                                                                                                 |
| `404.html`        | صفحة الخطأ                                                                                                                                                                    |

مزايا الواجهة: تبديل اللغة، وضع ليلي بأيقونة شمس/قمر، قائمة تنقل تُظلّل القسم الحالي، تصميم متجاوب للموبايل، ودعم لقارئات الشاشة ولوحة المفاتيح.

## التقنيات

- HTML وCSS وجافاسكربت خالصة، بدون إطار عمل ولا خطوة بناء.
- خط Cairo من Google Fonts.
- Supabase (مصادقة بروابط الدخول عبر البريد، وقاعدة PostgreSQL) للرسائل والمجتمع والتقييمات فقط. الصفحة الرئيسية لا تتصل بأي خادم.
- استضافة ثابتة على GitHub Pages.

## قاعدة البيانات

| الجدول            | الغرض                                                                                                                                              |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `conversations`   | محادثة بين صاحب طلب ومستقل، تُنشأ تلقائيًا عندما يراسل مستقل صاحب طلب في المجتمع، وفيها حالة المشروع (`active` / `completed`) يعتمدها صاحب المشروع |
| `messages`        | رسائل المحادثة، لا تُعدّل ولا تُحذف                                                                                                                |
| `community_posts` | طلبات المجتمع وحالتها (`pending` / `approved` / `rejected`) وعدد التصويتات                                                                         |
| `community_votes` | تصويت واحد لكل حساب على كل طلب                                                                                                                     |
| `profiles`        | ملفات الأعضاء العامة، وتبدأ `pending` ولا تظهر إلا بعد الموافقة                                                                                    |
| `notifications`   | إشعارات الجرس، تُنشأ تلقائيًا عند الموافقات وبدء المحادثة واعتماد الاكتمال والتقييم                                                                |
| `chat_reads`      | آخر رسالة قرأها كل عضو في كل محادثة (للعدّاد الأحمر)                                                                                               |
| `reviews`         | تقييمات المستقلين والموقع، ولا يُنشر أي تقييم قبل مراجعته                                                                                          |

قواعد الوصول (Row Level Security) في القاعدة نفسها:

- لا يقرأ المحادثة ولا يكتب فيها إلا طرفاها، وإنشاء المحادثات واعتماد الاكتمال عبر دوال في القاعدة (حد 10 محادثات يوميًا لكل حساب).
- لا يُقيَّم مستقل إلا من صاحب المشروع، بعد أن يصير مشروعه `completed`، ومرة واحدة لكل مشروع.
- تقييم الموقع لمن لديه محادثة على المنصة، ومرة واحدة.
- المشاركات والتقييمات تبدأ `pending` ولا تظهر للعامة إلا بعد الموافقة.
- حد أقصى 3 طلبات يوميًا لكل حساب في المجتمع.

## الأمان والخصوصية

- سياسة أمان محتوى (CSP) صارمة في كل صفحة.
- لا استخدام لـ `innerHTML`، والمحتوى يُعرض كنص عادي.
- تنظيف المدخلات والتحقق من الروابط والبريد وأرقام الواتساب.
- حقل مخفي ضد الروبوتات وفاصل 30 ثانية بين الإرسالين.
- تسجيل الدخول برابط يُرسل إلى البريد بدون كلمات مرور.
- لا كوكيز تتبّع، وتحليل الزيارات اختياري ومعطّل افتراضيًا.
- المفتاح العام فقط (publishable key) موجود في الموقع، وصلاحيات الوصول تحكمها قواعد القاعدة.
